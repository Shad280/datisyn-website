# DATISYN Logo – Concept C

This folder contains the primary vector logo for DATISYN.

## Files

- `datisyn-logo.svg` – Main vector logo (dark theme)
- `README.md` – This document

## Logo Concept

The DATISYN logo represents:

- **Data layers** → concentric shapes  
- **Intelligence core** → central node  
- **Orchestration** → diamond rotation showing movement  
- **Security and trust** → rounded geometry  

The geometric structure reflects how DATISYN unifies fragmented data into a single intelligence layer.

## Color Palette

- Background: `#031424`
- Primary cyan: `#00B3FF`
- Secondary cyan: `#29C3FF`
- Inner highlight: `#63D7FF`
- Wordmark text: `#E8F5FF`

## How to Export Variants

To create light, transparent, or mark-only versions:

- Remove the background `<rect>` for transparent usage  
- Copy only the `<g id="mark">` group for a symbol-only icon  
- Adjust viewBox for square exports  
- Export PNG in 32/64/128/512px for favicons or app icons
